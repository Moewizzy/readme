
# Reflection Questions



## 1. What accessibility enhancements were the most challenging to implement, and why?

The most challenging accessibility enhancements were making sure all interactive elements could be used with a keyboard and ensuring that images and buttons had proper descriptions. It was important to make the website easy to navigate for everyone, including people who use screen readers or have limited mobility. Getting everything to work correctly while maintaining a clean design required extra testing and attention to detail.


## 2.How do ARIA attributes improve the experience for users relying on assistive technologies?

ARIA attributes improve accessibility by providing additional information about website elements to assistive technologies such as screen readers. They help explain the purpose of buttons, menus, forms, and other interactive elements. For example, ARIA labels can describe a button’s function, while ARIA states can tell users whether a menu is expanded or collapsed. This makes websites easier to understand and navigate for people with disabilities.
## 3.What tools did you use to check color contrast, and how did they help?

Tools such as the WebAIM Contrast Checker and WAVE Accessibility Evaluation Tool can help identify color contrast problems on a website. They allow developers to check whether text and background colors meet accessibility standards. These tools are helpful because they make sure text is readable for people with visual impairments, including color blindness, and help improve the overall user experience.
